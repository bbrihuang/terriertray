# Inter Tight

The Latin variable WOFF2 is self-hosted so loading the app does not send font requests to a third party. The user selected Inter Tight from a font comparison preview.

- Source stylesheet: https://fonts.googleapis.com/css2?family=Inter+Tight:wght@400..700&display=swap
- WOFF2: https://fonts.gstatic.com/s/intertight/v9/NGSwv5HMAFg6IuGlBNMjxLsH8ag.woff2
- Upstream license: https://github.com/google/fonts/blob/main/ofl/intertight/OFL.txt
- License: SIL Open Font License 1.1; included in `OFL-Inter-Tight.txt`.

The app uses upright weights 400–700, with a system sans fallback and tabular numerals for changing nutrition totals.
